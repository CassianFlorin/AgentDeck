# Security

If you find a security problem in Waitlight, please report it privately through GitHub: **Security → Report a vulnerability** on this repository ([direct link](https://github.com/CassianFlorin/Waitlight/security/advisories/new)). Please don't open a public issue.

Only the latest release is supported. Fixes ship as a new release, which installed copies pick up through the in-app updater.

Things worth reporting include anything that lets a release, an update or a web page run code on your Mac, problems in how Waitlight stores SSH passwords (in the Keychain) or talks to your servers, and anything that leaks data outside your machine.

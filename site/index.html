一个窗口，
看住所有 Agent。One window
for every agent.

几个编程 Agent 一起跑的时候，麻烦的不是再开一个终端，而是你得不停去看：谁还在干活，谁停下来等你，关掉窗口之后那段对话去了哪。AgentDeck 把这些会话放在同一条侧边栏里。每一格都是真正的 Ghostty 终端，本地目录和 SSH 服务器排在一起。

The hard part of running several coding agents is not opening another terminal. It is seeing which one is still working, which one stopped to wait for you, and where a conversation went after the window closed. AgentDeck keeps those sessions in one sidebar. Each row is a real Ghostty terminal, local folders and SSH servers together.

状态Status

不用切过去，也知道该看谁。See who needs you without switching over.

每个 Agent 会话旁边有自己的状态。动效也有含义：还在干活，文字上会有一道光扫过；等你的时候，圆点外面的圈会扩出去。系统打开「减弱动态效果」后，这些动画会停。

Every agent session carries its own status, and the motion means something. While it is working, a light sweeps across the label. While it is waiting on you, a ring expands from the dot. With Reduce Motion on, the animation stops.

  1. 运行中Working

    这一轮还没结束。Claude Code 用它自己的 hooks 报告状态。AgentDeck 只在启动时加上参数，不改你的设置文件。其他 Agent 则靠回车、响铃、通知和进度来判断。

    This turn is still going. Claude Code reports through its own hooks. AgentDeck passes flags at launch and never edits your settings files. Other agents are read from generic signals: Return, the bell, notifications, and progress.

  2. 等你Needs you

    权限确认、一个问题，或一条通知。⌘⇧J 跳到下一个这样的会话。响铃和通知也会在 Dock 上标出来。

    A permission prompt, a question, or a notification. ⌘⇧J jumps to the next session that needs you. Bells and notifications also badge the Dock.

  3. 本轮完成Turn done

    这一轮结束了，会话还在。点进去可以接着看。退出之后再开，也会回到同一段对话。

    This turn is finished, and the session is still there. Open it to read the result. After it exits, starting it again returns to the same conversation.

  4. 已退出Exited

    Agent 进程结束了，你回到 shell。再启动会接着上次的对话。

    The agent process has ended and you are back at the shell. Starting it again continues the last conversation.

刚启动、还在等第一次输入时，显示「就绪」。普通 Shell 没有这些状态。SSH 断了以后会出现重连按钮，提示为「已断开」，⌘⇧R 也会重连。

Right after launch, before the first prompt, the label is 就绪. A plain shell has none of these states. A dropped SSH session gets a reconnect button, described as 已断开. ⌘⇧R reconnects too.

总览Overview

所有 Agent，列在一屏里。Every agent, on one screen.

侧边栏按会话排。Agent 多了以后，你想问的其实是另一件事：现在谁在等我。⇧⌘A 把终端换成一张列表，每个 Agent 一行，不管它在哪个会话、哪个文件夹。会话都还在后台跑着。

The sidebar is ordered by session. With enough agents, the question changes: who is waiting on me right now. ⇧⌘A swaps the terminal for a list with one row per agent, whichever session or folder it lives in. Every session keeps running behind it.

  • 等你的排在最前Waiting comes first

    按状态分组：等你、运行中、空闲、已退出。等你的那一行直接写着它在等什么，每行还有它在这个状态里停了多久。也可以改成按文件夹分组。

    Grouped by state: needs you, working, idle, exited. A waiting row says what it is waiting for, and every row shows how long it has been in that state. You can group by folder instead.

  • 不进去也能回Answer without going in

    选中一行，下面是它终端的最后几行。在输入框里打字、回车，回复就发给这个 Agent，你还留在列表里。

    Select a row and the last lines of its terminal appear below. Type in the field and press Return: the reply goes to that agent, and you stay on the list.

  • 回车进到它的会话Return opens its session

    ↩ 或双击，切到它所在的会话，光标落在它的窗格里。esc 或点侧边栏里任何一个会话，回到终端。

    ↩ or a double-click goes to its session, with the cursor in its pane. esc, or any session in the sidebar, returns to the terminal.

远程Remote

服务器上什么都不用装。Nothing to install on the server.

侧边栏的「服务器」有你添加的主机，也有 ~/.ssh/config 里的别名，Include 进来的文件也算。可以填地址、用户、端口、密钥或 ssh-agent，也支持 ProxyJump。密码放在钥匙串里。

Servers lists hosts you add and every alias in ~/.ssh/config, including files pulled in with Include. You can set the address, user, port, key or ssh-agent, and ProxyJump. Passwords go in the Keychain.

默认是自动。机器上已经有 tmux 或 zellij 就用它，没有就开一个普通登录 shell，不会催你去装。连接断了可以重连。如果当时跑在 tmux 或 zellij 里，会挂回原来的会话，里面的 Agent 还在。没有多路复用器的话，就按你配置的目录重新登录。

Auto is the default. If the machine already has tmux or zellij, AgentDeck uses it. If not, you get a normal login shell, with no prompt to install anything. Reconnecting a tmux or zellij session attaches again, so the agent is still there. Without a multiplexer, it logs in again, in the directory you set.

性能面板跟着当前会话。看 SSH 会话时，采样的是那台服务器：只开一条 SSH，用一小段 POSIX shell 去读 /proc。服务器上仍然不用装东西。远程采样目前只支持 Linux。

The performance panel follows the selected session. For SSH it samples that server over one connection: a small POSIX shell loop reading /proc. Still nothing to install. Remote sampling currently supports Linux only.

对话Conversations

关掉窗口，对话还在。Close the window. The conversation stays.

Claude Code 和 Grok 在启动时就带上 AgentDeck 分配的对话 id。Codex 会在启动之后，从它自己的 ~/.codex/sessions 里对上 id。重启 App，或者一个已经退出的 Agent 再开，都会回到这段对话。⇧⌘O 按文件夹列出这个 Agent 过去的对话。

Claude Code and Grok start with a conversation id AgentDeck assigns. Codex is matched, after launch, to an id in its own ~/.codex/sessions directory. Relaunching the app, or starting an agent that had exited, resumes that conversation. ⇧⌘O lists past conversations for a folder.

分屏、分组和 SSH 连接也会按退出前的样子回来。第一次打开、没有可恢复的内容时，会在家目录开一个 shell。

Splits, groups, and SSH connections come back the way you left them. With nothing to restore, AgentDeck opens a shell in your home directory.

你的配置Your config

~/.config/ghostty/config

字体、主题和快捷键直接沿用。设置 → 终端里改过的项叠在这份配置上面，立刻作用到所有终端，但不会写回文件。中文默认统一用苹方显示，粗细和标点位置都一致，也可以换成别的字体。设置 → 外观可以调窗口的不透明度和毛玻璃，文字始终不透明。AgentDeck 本身只有深色。

Fonts, themes, and keybinds come straight from this file. Changes in Settings → Terminal are layered on top and applied to every terminal immediately. The file is never modified. Chinese, Japanese, and Korean text uses PingFang SC by default, so weights and punctuation stay consistent; you can pick another font. Settings → Appearance sets opacity and blur. Text stays opaque. AgentDeck is always dark.

还有这些Also

  • 内置 Claude Code、Codex、Grok、Gemini 和 Shell。其他命令行工具可以自己加。还没安装的，会给出安装命令。命令是打进登录 shell 的，Agent 退出以后，你还在那个 shell 里。Built in: Claude Code, Codex, Grok, Gemini, and a shell. Any other CLI can be added. Ones that are not installed come with an install command. The command is typed into your login shell, so when the agent exits you are still in that shell.
  • 状态跟着窗格走，不跟着会话。在分屏里自己敲 claude 或 codex，AgentDeck 也认得出来，它会有自己的状态，也会出现在总览里。Status belongs to the pane, not the session. Type claude or codex into a split yourself and AgentDeck notices: it gets its own status and its own row in the overview.
  • 剪贴板里如果是截图，⌘V 会先存成 PNG，再贴上路径，这样就能把图交给 Agent。拷进来或拖进来的文件，会变成 shell 转义后的路径。If the clipboard holds a screenshot, ⌘V saves a PNG and pastes the path, which is how you hand an image to an agent. Copied or dragged files paste as shell-escaped paths.
  • 中文、日文、韩文输入法可以用，候选窗贴着光标。Chinese, Japanese, and Korean input methods work, with the candidate window anchored at the cursor.
  • 会话可以重命名，也可以放进分组。分组是侧边栏里可折叠的一段。Sessions can be renamed or moved into a group. A group is a collapsible section in the sidebar.
  • 性能面板里还有 Docker。可以看容器日志、进容器开一个 shell，也可以启动、停止或重启。从容器打开的会话，下次启动 App 时不会恢复。The performance panel also lists Docker containers. You can open logs, a shell inside a container, and start, stop, or restart one. Sessions opened from a container are not restored on the next launch.
  • 每天会查一次更新，菜单里也可以自己检查。更新来自 GitHub Releases，要有 EdDSA 签名，并且 Developer ID 得和当前这个 App 一致。如果有 Agent 正处在这一轮里，重启前会先问你。AgentDeck checks for an update once a day, and you can check from the menu. Updates come from GitHub Releases. Each one is EdDSA-signed and must carry the same Developer ID as the app you have. If an agent is mid-turn, it asks before restarting.

分屏移动、查找步进和其他细节在 功能说明 里。Moving between panes, stepping through matches, and the rest are in the feature notes.
